# Дача: удалённый доступ к компьютерам через сайт

Возможности: **несколько компьютеров одновременно** (переключатель вверху сайта), **файлы** (просмотр, скачивание, загрузка — по умолчанию виден весь диск), **экран** (живой поток + снимок), **камера** (выключена по умолчанию), **управление мышью и клавиатурой** прямо по картинке экрана, **кнопка удаления** выбранного компьютера, **вход по коду (2FA)** и **журнал действий**.

```
Браузер ──HTTPS──> сервер (server/: вход + сайт) ──Tailscale──> агент на компьютере 1 (agent/, Windows)
                                                   └─Tailscale──> агент на компьютере 2 (agent/, Windows)
```

- `agent/` — работает на каждом подключаемом компьютере. Отдаёт только разрешённые папки и картинку экрана, требует токен, слушает только адрес в VPN и сам сообщает сайту свой адрес и свою личность (`device_id`) — так сайт различает несколько компьютеров.
- `server/` — работает на твоём сервере. Вход по логину и паролю (+ код 2FA, если включён), веб-интерфейс, проксирование к агентам, список подключённых компьютеров. Токен агента браузер не видит. Выдаёт персональный установщик.
- `install/` — установщики: для сервера (одна команда) и для каждого компьютера (один файл или одна команда).

## Установка

### 1. Сервер (Ubuntu/Debian), один раз

Нужны: SSH с правами root и домен (подойдёт бесплатный поддомен на duckdns.org, указывающий на IP сервера).

```bash
curl -fsSL https://raw.githubusercontent.com/coldout456-cloud/ters1/main/install/install-server.sh | sudo bash -s -- ИМЯ.duckdns.org
```

Скрипт проверяет домен и порты, ставит нужные пакеты, скачивает код, создаёт окружение, спрашивает пароль для входа на сайт (логин `admin`), создаёт службу `dacha`, ставит Caddy с HTTPS и Tailscale. Запускать можно повторно: код обновится, а `.env` (пароль, токены) и остальные службы сервера не тронутся. Если порты 80/443 заняты другой программой, скрипт остановится, ничего не изменив.

**Необязательно, но рекомендуется** (тогда на даче вообще ничего не нужно нажимать в Tailscale): создай в панели Tailscale ключ (Settings → Keys → Generate auth key, галочка **Reusable**, срок 90 дней) и выполни на сервере `dacha-set-tskey`. Команда спросит ключ скрытым вводом.

### 2. Каждый компьютер (Windows 10/11)

Повторяется для каждого компьютера, который нужно подключить — сайт сам различает их и показывает в переключателе вверху страницы. Два способа, оба ставят одно и то же в `%LOCALAPPDATA%\DachaAgent` (это папка вида `C:\Users\имя\AppData\Local\DachaAgent` — она скрыта в проводнике, пока не включить «Показывать скрытые элементы», в отличие от рабочего стола или диска `C:\`): Python, VPN, агент, брандмауэр, автозапуск при входе в Windows, проверка, регистрация на сайте. Вопросов нет: адрес сайта, токен и ключ Tailscale вшиваются сайтом. Открываются стандартные папки пользователя (Документы, Рабочий стол, Изображения, Видео, Музыка, Загрузки); изменить список можно в `%LOCALAPPDATA%\DachaAgent\agent\.env`, строка `ALLOWED_DIRS`.

На вкладке «Установка» перед скачиванием/копированием можно вписать **имя компьютера** (необязательно) — так в переключателе сразу будет понятно, «Дача» это или «Квартира», а не два одинаковых пункта. Если не вписать, компьютер подпишется своим именем в Windows; переименовать можно в любой момент прямо на сайте, без переустановки.

**Командой (рекомендуется — ничего не остаётся на диске).** Подходит, если за компьютером могут оказаться другие люди (например, дети) и файл на рабочем столе могут случайно или специально удалить, пока он ждёт запуска.

1. На нужном компьютере открой свой сайт, войди, вкладка **«Установка»**.
2. Открой PowerShell от имени администратора (правой кнопкой по «Пуск» → «Terminal (администратор)» или «Windows PowerShell (администратор)» → «Да»).
3. Скопируй готовую команду с сайта, вставь в это окно, нажми Enter.
4. Окно почти сразу можно закрыть (команда сама завершает его через пару секунд) — сама установка идёт дальше в скрытом окне, которое никак не видно. Результат смотри на сайте (появился ли компьютер) через 3–5 минут или в журнале `%LOCALAPPDATA%\DachaAgent\install.log`.

Единственное окно, которое обязательно появится, — это сам запрос Windows «Разрешить вносить изменения?» при открытии администраторского PowerShell; его показывает сама система, и его нельзя убрать никаким скриптом. Дальше ничего не сохраняется на диск как отдельный файл, поэтому и удалить нечего, и ничего не видно — так же незаметно, как установка файлом.

**Файлом (проще, но файл лежит на диске до запуска).**

1. Вкладка **«Установка»** → **«Скачать установщик для дачи»**: скачается `dacha-install.bat`.
2. Сразу двойной клик, в окне Windows нажми «Да». Если SmartScreen предупредит, выбери «Подробнее» → «Выполнить в любом случае».
3. Подожди 3–5 минут — окон и вопросов больше не будет. По окончании файл удалит сам себя, потому что в нём зашиты ключи. Если за это время компьютер выключат или файл удалят, установка не завершится; результат смотри на сайте или в `%LOCALAPPDATA%\DachaAgent\install.log`.

Если ключа Tailscale на сервере нет: способ файлом в этом случае не запустится вообще (чтобы не открыть неожиданно браузер с чужой страницей входа) — на сервере выполни `dacha-set-tskey`. Способ командой в этом случае сам откроет страницу входа в Tailscale в твоём браузере, достаточно нажать «Connect» (ты всё равно сидишь рядом и это видишь).

**Обновление:** скачай установщик на сайте и запусти ещё раз на том же компьютере (папки и имя сохранятся). **Удаление:** кнопка «Удалить этот компьютер» на сайте (вкладка «Установка» — удаляет именно тот компьютер, что выбран в переключателе) либо вручную `%LOCALAPPDATA%\DachaAgent\uninstall.bat` на самом компьютере.

Чтобы компьютер поднимался сам после перезагрузки или отключения света, один раз вручную: включить автоматический вход в Windows (`netplwiz`) и в BIOS параметр «включаться при появлении питания». Проверь также, что сам **Tailscale запускается при входе в Windows** (Диспетчер задач → «Автозагрузка» → Tailscale должен быть «Включено») — агент ждёт его адрес перед стартом, и если Tailscale не поднимается сам, не поднимется и агент, даже с включённым автовходом. Скрипт не может сделать это за тебя без хранения пароля Windows, и **включить питание удалённо по сети (Wake-on-LAN), если компьютер выключен или не вошёл в Windows, сайт не умеет и не может**: агент — это просто программа внутри Windows, и пока компьютер выключен, запускать её попросту некому ни на этом компьютере, ни откуда-то ещё через интернет.

> Агент работает в сессии пользователя, а не как служба Windows: служба не видит рабочий стол. Поэтому нужен вход в систему, а на экране блокировки картинка чёрная.

Запасной путь без сайта: файл `install/install.bat` из репозитория (кнопка «Download raw file» на GitHub) задаёт вопросы вместо вшитых значений.

### Что умеет после установки

- **Несколько компьютеров** — переключатель вверху сайта. Список со статусом «в сети/не в сети», переименованием и возможностью «забыть» компьютер (убрать из списка на сайте, не трогая сам компьютер) — вкладка «Установка» → «Мои компьютеры».
- **Файлы** — по умолчанию виден весь диск (`ALLOW_ALL_FILES=1`). Чтобы ограничить конкретными папками: в `%LOCALAPPDATA%\DachaAgent\agent\.env` поставь `ALLOW_ALL_FILES=0` и заполни `ALLOWED_DIRS`, затем перезайди в Windows.
- **Экран** — поток и снимок, выбор монитора, настройка кадров/с, размера и качества.
- **Камера** — выключена по умолчанию (`CAMERA_ENABLED=0` в `.env`, включить вручную и перезайти в Windows). Отдельная вкладка «Камера» на сайте.
- **Управление мышью и клавиатурой** — на вкладке «Экран» кнопка «Управление». Когда включено: клик по картинке = щелчок на компьютере, правый клик, двойной клик и колесо работают; клик по картинке, затем печатай — буквы, Enter, Backspace, Tab, Esc, стрелки и Delete уходят на компьютер, плюс кнопки быстрых сочетаний (Ctrl+C/V/Z/A, Alt+Tab). Выключить совсем: `INPUT_ENABLED=0` в том же `.env`.
- **Удаление компьютера** — на вкладке «Установка» кнопка «Удалить этот компьютер» (удаляет тот, что выбран в переключателе сейчас, а не все сразу). Агент снимает автозапуск и правило брандмауэра (для этого установленная задача запускается с повышенными правами, если пользователь — администратор) и удаляет свою папку целиком. Если прав не хватит, папка и процессы всё равно удалятся, а задача автозапуска и правило брандмауэра останутся «пустышками» — их можно убрать вручную.
- **Вход по коду (2FA)** — выключен по умолчанию. Включить на сервере: `dacha-set-2fa` (выдаст ключ для Google Authenticator/Authy и т.п.), выключить: `dacha-set-2fa off`.
- **Журнал действий** — вкладка «Журнал»: вход/выход, скачивания и загрузки файлов, удаление и переименование компьютеров, с временем, IP и именем компьютера.

## Ручной запуск для проверки на одном компьютере

Нужен Python 3.10+. В `agent/` и `server/` лежат шаблоны `env.example` (скопируй в `.env`).

```powershell
cd agent
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy env.example .env      # впиши токен и папки; SCREEN_BACKEND=test — картинка-заглушка вместо экрана
python agent.py
```

```powershell
cd server
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy env.example .env
python security.py         # выдаст ADMIN_PASSWORD_HASH
python server.py
```

Для проверки по `http://` в `server/.env`: `COOKIE_SECURE=0`, `TRUST_PROXY=0`. Агента в этом режиме добавляй через раздел «Мои компьютеры» на сайте (сервер узнаёт его адрес сам, как только агент один раз зарегистрируется) — отдельного `AGENT_URL` в `.env` больше нет. Сайт: http://127.0.0.1:8000.

## Безопасность

Что уже есть:

- Вход по паролю (хэш scrypt), блокировка на 15 минут после 5 неудачных попыток, пауза на каждую неудачу.
- **Вход по коду (2FA)**, если включён (`dacha-set-2fa` на сервере): код из приложения-аутентификатора проверяется дополнительно к паролю, по стандартному алгоритму TOTP (как в Google Authenticator). Выключен по умолчанию, чтобы случайная ошибка в настройке не заблокировала владельца от собственного сайта.
- Сессия в подписанной куке: `Secure`, `HttpOnly`, `SameSite=Strict`, живёт `SESSION_HOURS` часов. У запросов-изменений проверяется `Origin`.
- Файлы всегда скачиваются как вложение (HTML из папки не выполнится на сайте). В режиме папок (`ALLOW_ALL_FILES=0`) `..`, абсолютные пути и симлинки наружу блокируются.
- Порт каждого агента открыт в брандмауэре только для сети Tailscale (`100.64.0.0/10`), агент слушает только адрес Tailscale. Все компьютеры используют общий токен, но различаются сайтом по собственному `device_id`, который агент генерирует при первом запуске и хранит у себя — подменить один компьютер другим, уже зарегистрированным, нельзя.
- **Камера выключена по умолчанию** (`CAMERA_ENABLED=0`) — её включают осознанно, отдельно от экрана и файлов.
- Клавиатура не «удерживает» нажатую клавишу между отдельными запросами с сайта: даже если сетевой запрос на отпускание клавиши потеряется, на компьютере не останется зажатой клавиши.
- **Журнал действий** — вход/выход (успешный и неудачный), скачивания и загрузки файлов, удаление и переименование компьютеров: кто, когда, с какого IP и для какого компьютера. Доступен на вкладке «Журнал», хранится на сервере, старые записи обрезаются автоматически.
- **Внимание про полный доступ.** По умолчанию включены доступ ко всему диску (`ALLOW_ALL_FILES=1`), управление мышью и клавиатурой и запуск агента с повышенными правами. Это делает удобным ценой того, что любой, кто получит и пароль от сайта, и токен агента, получит весь диск и управление. Поэтому держи пароль сильным, включи 2FA и никому не давай установщик/команду. Ограничить можно флагами `ALLOW_ALL_FILES=0` и `INPUT_ENABLED=0`.
- Регистрация агента на сайте: по токену, с блокировкой перебора, принимается только IPv4 из сети Tailscale. Даже с верным токеном нельзя направить сайт на чужой адрес.
- Персональный установщик отдаётся только после входа, не кешируется, значения в него вшиваются только после строгой проверки (нельзя подмешать команды, включая вписанное имя компьютера), файл удаляет сам себя после успешной установки.
- Строгая CSP, `X-Frame-Options: DENY`, `nosniff`, HSTS.

Чего пока нет:

- **Принудительного завершения сессий** — сменить `SESSION_SECRET` вручную значит разлогинить всех сразу; отдельной кнопки «выйти везде» нет.
- **Включения компьютера по сети (Wake-on-LAN).** Не реализовано осознанно: это требует устройства, которое само всегда онлайн в той же локальной сети, что и спящий компьютер, и может послать ему «магический пакет» — такого устройства в этой схеме нет (на каждой площадке стоит только сам Windows-компьютер, который не может включить себя, пока выключен).

О ключах:

- Установщик содержит токен агента и (если задан) ключ Tailscale. Не пересылай его. Если файл всё же утёк: отзови ключ в панели Tailscale и смени `AGENT_TOKEN` в `server/.env`.
- Тот, кто управляет репозиторием на GitHub, управляет и установщиками. Включи двухфакторную защиту на GitHub-аккаунте. Секретов в репозитории быть не должно, а автообновления у агента намеренно нет.

## Устройство

| Файл | Что внутри |
|---|---|
| `agent/agent.py` | Файлы (`/files/list`, `/files/download`, `/files/upload`), экран (`/screen/*`), камера (`/camera/*`), мышь и клавиатура (`/input/move`, `/input/click`, `/input/scroll`, `/input/key`), удаление (`/self-destruct`), хранит и сообщает сайту свой `device_id` и имя |
| `server/server.py` | Вход (+2FA), сессии, список компьютеров, проксирование к нужному агенту по `device`, регистрация/переименование/удаление компьютеров, выдача установщика, журнал действий, защитные заголовки |
| `server/dacha_installer.py` | Сборка персонального установщика (с необязательным именем компьютера) и проверка адреса агента |
| `server/security.py` | Хэширование пароля, проверка кода 2FA (TOTP) |
| `server/static/` | Веб-интерфейс: переключатель компьютеров, файлы, экран, камера, управление, журнал, установка (HTML, CSS, JS без сборки) |
| `install/install-server.sh` | Установка сервера одной командой; там же `dacha-set-tskey`, `dacha-set-2fa`, `dacha-list-devices` |
| `install/install.ps1` | Установка агента на Windows (запускается из `dacha-install.bat`), без вопросов — включая необязательное имя компьютера |
| `install/install.bat` | Запасной установщик с вопросами, включая имя компьютера |
| `install/run-agent.ps1` | Запуск агента при входе: ждёт Tailscale, перезапускает при падении |

Дальше по плану: пока ничего не запланировано — всё из предыдущего списка реализовано, кроме включения по сети (см. «Безопасность» — architecturally не получится без отдельного всегда-включённого устройства в той же локальной сети).
