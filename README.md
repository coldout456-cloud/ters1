# Дача: удалённый доступ к компьютеру через сайт

Тестовая версия: **файлы** (просмотр, скачивание, загрузка) и **экран** (живой поток + снимок).

```
Браузер ──HTTPS──> сервер (server/: вход + сайт) ──Tailscale──> агент на даче (agent/, Windows)
```

- `agent/` — работает на дачном компьютере. Отдаёт только разрешённые папки и картинку экрана, требует токен, слушает только адрес в VPN.
- `server/` — работает на твоём сервере. Вход по логину и паролю, веб-интерфейс, проксирование к агенту. Токен агента браузер не видит.
- `install/` — установщики: для сервера (одна команда) и для дачи (двойной клик).

## Установка в один клик

### 1. Сервер (Ubuntu/Debian)

Нужны: SSH с правами root и домен (подойдёт бесплатный поддомен на duckdns.org, указывающий на IP сервера).

```bash
curl -fsSL https://raw.githubusercontent.com/coldout456-cloud/ters1/main/install/install-server.sh | sudo bash -s -- ИМЯ.duckdns.org
```

Скрипт: проверяет домен и порты, ставит нужные пакеты, скачивает код, создаёт окружение, спрашивает пароль для входа на сайт (логин `admin`), создаёт службу `dacha`, ставит Caddy с HTTPS и Tailscale. В конце печатает **токен агента**: он понадобится на даче.

Запускать можно повторно: код обновится, а `.env` (пароль, токены) и остальные службы сервера не тронутся. Если порты 80/443 заняты другой программой, скрипт остановится ничего не изменив.

### 2. Дача (Windows 10/11)

1. Открой https://github.com/coldout456-cloud/ters1/blob/main/install/install.bat и нажми кнопку скачивания («Download raw file»).
2. Двойной клик по `install.bat`, в окне Windows нажми «Да». Если SmartScreen предупредит, выбери «Подробнее», затем «Выполнить в любом случае».
3. Ответь на три вопроса: токен агента, ключ Tailscale (можно пропустить и войти через браузер), какие папки открыть.
4. Дальше всё само: Python, VPN, зависимости, брандмауэр, автозапуск при входе в Windows, проверка.
5. В конце появится команда вида `dacha-set-agent 100.x.y.z`. Выполни её на сервере по SSH.

Без файла, из PowerShell от администратора:
```powershell
irm https://raw.githubusercontent.com/coldout456-cloud/ters1/main/install/install.ps1 | iex
```

Чтобы дача поднималась сама после перезагрузки: включи автоматический вход в Windows (`netplwiz`) и в BIOS параметр «включаться при появлении питания».

**Обновление:** запусти `install.bat` ещё раз (токен и папки сохранятся). **Удаление:** `C:\DachaAgent\uninstall.bat`.

> Агент работает в сессии пользователя, а не как служба Windows: служба не видит рабочий стол. Поэтому нужен вход в систему, а на экране блокировки картинка чёрная.

## Ручной запуск для проверки на одном компьютере

Нужен Python 3.10+. В `agent/` и `server/` лежат шаблоны `env.example` (скопируй в `.env`).

```powershell
cd agent
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy env.example .env      # впиши токен и папки; SCREEN_BACKEND=test — картинка-заглушка вместо экрана
python agent.py
```

```powershell
cd server
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy env.example .env
python security.py         # выдаст ADMIN_PASSWORD_HASH
python server.py
```

Для проверки по `http://` в `server/.env`: `AGENT_URL=http://127.0.0.1:8765`, `COOKIE_SECURE=0`, `TRUST_PROXY=0`. Сайт: http://127.0.0.1:8000.

## Безопасность

Что уже есть:

- Вход по паролю (хэш scrypt), блокировка на 15 минут после 5 неудачных попыток, пауза на каждую неудачу.
- Сессия в подписанной куке: `Secure`, `HttpOnly`, `SameSite=Strict`, живёт `SESSION_HOURS` часов. У запросов-изменений проверяется `Origin`.
- Агент отдаёт только файлы из разрешённых папок: `..`, абсолютные пути и симлинки наружу блокируются. Файлы всегда скачиваются как вложение. Установщик не даёт выбрать диск целиком, профиль пользователя, `AppData` и системные папки.
- Порт агента открыт в брандмауэре только для сети Tailscale (`100.64.0.0/10`), агент слушает только адрес Tailscale.
- Токен агента сравнивается за постоянное время; файл `.env` на даче доступен только пользователю и администраторам.
- Строгая CSP, `X-Frame-Options: DENY`, `nosniff`, HSTS.

Чего пока нет:

- **Двухфакторной аутентификации.** Для сайта, который показывает твой экран, это следующий шаг.
- Принудительного завершения сессий (сменить `SESSION_SECRET` значит разлогинить всех) и журнала действий.

Про репозиторий: тот, кто управляет репозиторием на GitHub, управляет и установщиками. Включи двухфакторную защиту на GitHub-аккаунте. Секретов (токенов, паролей, ключей) в репозитории быть не должно, а автообновления у агента намеренно нет.

## Устройство

| Файл | Что внутри |
|---|---|
| `agent/agent.py` | Файлы (`/files/list`, `/files/download`, `/files/upload`), экран (`/screen/stream` MJPEG, `/screen/snapshot`, `/screen/monitors`) |
| `server/server.py` | Вход, сессии, проксирование к агенту, защитные заголовки |
| `server/security.py` | Хэширование пароля |
| `server/static/` | Веб-интерфейс (HTML, CSS, JS без сборки) |
| `install/install-server.sh` | Установка сервера одной командой |
| `install/install.bat`, `install.ps1` | Установка агента на Windows |
| `install/run-agent.ps1` | Запуск агента при входе: ждёт Tailscale, перезапускает при падении |

Дальше по плану: камера, управление мышью и клавиатурой, включение по сети, 2FA.
