# Дача: удалённый доступ к компьютеру через сайт

Возможности: **файлы** (просмотр, скачивание, загрузка — по умолчанию виден весь диск), **экран** (живой поток + снимок), **управление мышью** (клик, правый клик, двойной клик, колесо прямо по картинке экрана) и **кнопка удаления агента** с дачи.

```
Браузер ──HTTPS──> сервер (server/: вход + сайт) ──Tailscale──> агент на даче (agent/, Windows)
```

- `agent/` — работает на дачном компьютере. Отдаёт только разрешённые папки и картинку экрана, требует токен, слушает только адрес в VPN и сам сообщает его сайту.
- `server/` — работает на твоём сервере. Вход по логину и паролю, веб-интерфейс, проксирование к агенту. Токен агента браузер не видит. Выдаёт персональный установщик для дачи.
- `install/` — установщики: для сервера (одна команда) и для дачи (один файл).

## Установка

### 1. Сервер (Ubuntu/Debian), один раз

Нужны: SSH с правами root и домен (подойдёт бесплатный поддомен на duckdns.org, указывающий на IP сервера).

```bash
curl -fsSL https://raw.githubusercontent.com/coldout456-cloud/ters1/main/install/install-server.sh | sudo bash -s -- ИМЯ.duckdns.org
```

Скрипт проверяет домен и порты, ставит нужные пакеты, скачивает код, создаёт окружение, спрашивает пароль для входа на сайт (логин `admin`), создаёт службу `dacha`, ставит Caddy с HTTPS и Tailscale. Запускать можно повторно: код обновится, а `.env` (пароль, токены) и остальные службы сервера не тронутся. Если порты 80/443 заняты другой программой, скрипт остановится, ничего не изменив.

**Необязательно, но рекомендуется** (тогда на даче вообще ничего не нужно нажимать в Tailscale): создай в панели Tailscale ключ (Settings → Keys → Generate auth key, галочка **Reusable**, срок 90 дней) и выполни на сервере `dacha-set-tskey`. Команда спросит ключ скрытым вводом.

### 2. Дача (Windows 10/11)

Два способа, оба ставят одно и то же в `%LOCALAPPDATA%\DachaAgent` (это папка вида `C:\Users\имя\AppData\Local\DachaAgent` — она скрыта в проводнике, пока не включить «Показывать скрытые элементы», в отличие от рабочего стола или диска `C:\`): Python, VPN, агент, брандмауэр, автозапуск при входе в Windows, проверка, регистрация на сайте. Вопросов нет: адрес сайта, токен и ключ Tailscale вшиваются сайтом. Открываются стандартные папки пользователя (Документы, Рабочий стол, Изображения, Видео, Музыка, Загрузки); изменить список можно в `%LOCALAPPDATA%\DachaAgent\agent\.env`, строка `ALLOWED_DIRS`.

**Командой (рекомендуется — ничего не остаётся на диске).** Подходит, если за компьютером могут оказаться другие люди (например, дети) и файл на рабочем столе могут случайно или специально удалить, пока он ждёт запуска.

1. На дачном компьютере открой свой сайт, войди, вкладка **«Установка»**.
2. Открой PowerShell от имени администратора (правой кнопкой по «Пуск» → «Terminal (администратор)» или «Windows PowerShell (администратор)» → «Да»).
3. Скопируй готовую команду с сайта, вставь в это окно, нажми Enter.
4. Подожди 3–5 минут, прогресс виден прямо в окне.

Единственное окно, которое обязательно появится, — это сам запрос Windows «Разрешить вносить изменения?» при открытии администраторского PowerShell; его показывает сама система, и его нельзя убрать никаким скриптом. Дальше ничего не сохраняется на диск как отдельный файл, поэтому и удалить нечего.

**Файлом (проще, но файл лежит на диске до запуска).**

1. Вкладка **«Установка»** → **«Скачать установщик для дачи»**: скачается `dacha-install.bat`.
2. Сразу двойной клик, в окне Windows нажми «Да». Если SmartScreen предупредит, выбери «Подробнее» → «Выполнить в любом случае».
3. Подожди 3–5 минут — окон и вопросов больше не будет. По окончании файл удалит сам себя, потому что в нём зашиты ключи. Если за это время компьютер выключат или файл удалят, установка не завершится; результат смотри на сайте или в `%LOCALAPPDATA%\DachaAgent\install.log`.

Если ключа Tailscale на сервере нет: способ файлом в этом случае не запустится вообще (чтобы не открыть неожиданно браузер с чужой страницей входа) — на сервере выполни `dacha-set-tskey`. Способ командой в этом случае сам откроет страницу входа в Tailscale в твоём браузере, достаточно нажать «Connect» (ты всё равно сидишь рядом и это видишь).

**Обновление:** скачай установщик на сайте и запусти ещё раз (папки сохранятся). **Удаление:** `%LOCALAPPDATA%\DachaAgent\uninstall.bat`.

Чтобы дача поднималась сама после перезагрузки или отключения света, один раз вручную: включить автоматический вход в Windows (`netplwiz`) и в BIOS параметр «включаться при появлении питания». Скрипт не может сделать это за тебя без хранения пароля Windows.

> Агент работает в сессии пользователя, а не как служба Windows: служба не видит рабочий стол. Поэтому нужен вход в систему, а на экране блокировки картинка чёрная.

Запасной путь без сайта: файл `install/install.bat` из репозитория (кнопка «Download raw file» на GitHub) задаёт три вопроса вместо вшитых значений.

### Что умеет после установки

- **Файлы** — по умолчанию виден весь диск (`ALLOW_ALL_FILES=1`). Чтобы ограничить конкретными папками: в `%LOCALAPPDATA%\DachaAgent\agent\.env` поставь `ALLOW_ALL_FILES=0` и заполни `ALLOWED_DIRS`, затем перезайди в Windows.
- **Экран** — поток и снимок, выбор монитора.
- **Управление мышью** — на вкладке «Экран» кнопка «Управление». Когда включено: клик по картинке = щелчок на даче, правый клик, двойной клик и колесо работают. Выключить совсем: `INPUT_ENABLED=0` в том же `.env`.
- **Удаление агента** — на вкладке «Установка» кнопка «Удалить агент с дачи». Агент снимает автозапуск и правило брандмауэра (для этого установленная задача запускается с повышенными правами, если пользователь — администратор) и удаляет свою папку целиком. Если прав не хватит, папка и процессы всё равно удалятся, а задача автозапуска и правило брандмауэра останутся «пустышками» — их можно убрать вручную.

## Ручной запуск для проверки на одном компьютере

Нужен Python 3.10+. В `agent/` и `server/` лежат шаблоны `env.example` (скопируй в `.env`).

```powershell
cd agent
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy env.example .env      # впиши токен и папки; SCREEN_BACKEND=test — картинка-заглушка вместо экрана
python agent.py
```

```powershell
cd server
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy env.example .env
python security.py         # выдаст ADMIN_PASSWORD_HASH
python server.py
```

Для проверки по `http://` в `server/.env`: `AGENT_URL=http://127.0.0.1:8765`, `COOKIE_SECURE=0`, `TRUST_PROXY=0`. Сайт: http://127.0.0.1:8000.

## Безопасность

Что уже есть:

- Вход по паролю (хэш scrypt), блокировка на 15 минут после 5 неудачных попыток, пауза на каждую неудачу.
- Сессия в подписанной куке: `Secure`, `HttpOnly`, `SameSite=Strict`, живёт `SESSION_HOURS` часов. У запросов-изменений проверяется `Origin`.
- Файлы всегда скачиваются как вложение (HTML из папки не выполнится на сайте). В режиме папок (`ALLOW_ALL_FILES=0`) `..`, абсолютные пути и симлинки наружу блокируются.
- Порт агента открыт в брандмауэре только для сети Tailscale (`100.64.0.0/10`), агент слушает только адрес Tailscale.
- **Внимание про полный доступ.** По умолчанию включены доступ ко всему диску (`ALLOW_ALL_FILES=1`), управление мышью и запуск агента с повышенными правами. Это делает удобным ценой того, что любой, кто получит и пароль от сайта, и токен агента, получит весь диск и управление. Поэтому держи пароль сильным, 2FA — в планах, и никому не давай установщик/команду. Ограничить можно флагами `ALLOW_ALL_FILES=0` и `INPUT_ENABLED=0`.
- Регистрация агента на сайте: по токену, с блокировкой перебора, принимается только IPv4 из сети Tailscale. Даже с верным токеном нельзя направить сайт на чужой адрес.
- Персональный установщик отдаётся только после входа, не кешируется, значения в него вшиваются только после строгой проверки (нельзя подмешать команды), файл удаляет сам себя после успешной установки.
- Строгая CSP, `X-Frame-Options: DENY`, `nosniff`, HSTS.

Чего пока нет:

- **Двухфакторной аутентификации.** Для сайта, который показывает твой экран, это следующий шаг.
- Принудительного завершения сессий (сменить `SESSION_SECRET` значит разлогинить всех) и журнала действий.

О ключах:

- Установщик содержит токен агента и (если задан) ключ Tailscale. Не пересылай его. Если файл всё же утёк: отзови ключ в панели Tailscale и смени `AGENT_TOKEN` в `server/.env`.
- Тот, кто управляет репозиторием на GitHub, управляет и установщиками. Включи двухфакторную защиту на GitHub-аккаунте. Секретов в репозитории быть не должно, а автообновления у агента намеренно нет.

## Устройство

| Файл | Что внутри |
|---|---|
| `agent/agent.py` | Файлы (`/files/list`, `/files/download`, `/files/upload`), экран (`/screen/*`), мышь (`/input/move`, `/input/click`, `/input/scroll`), удаление (`/self-destruct`), сообщает сайту свой адрес |
| `server/server.py` | Вход, сессии, проксирование к агенту, регистрация агента, выдача установщика, защитные заголовки |
| `server/dacha_installer.py` | Сборка персонального установщика и проверка адреса агента |
| `server/security.py` | Хэширование пароля |
| `server/static/` | Веб-интерфейс (HTML, CSS, JS без сборки) |
| `install/install-server.sh` | Установка сервера одной командой |
| `install/install.ps1` | Установка агента на Windows (запускается из `dacha-install.bat`) |
| `install/install.bat` | Запасной установщик с тремя вопросами |
| `install/run-agent.ps1` | Запуск агента при входе: ждёт Tailscale, перезапускает при падении |
